# Quiz de Normas de Segurança da Informação

Um aplicativo web interativo e leve desenvolvido em **HTML, CSS e JavaScript** com tema escuro, focado em fixar o conhecimento sobre **ISO/IEC 27001**, **ISO/IEC 27002**, **tríade CID**, **gestão de riscos** e **auditoria**.

---

## Funcionalidades
- **35 Questões Práticas:** Baseadas em conceitos essenciais de Segurança da Informação.
- **Tema Escuro (Dark Mode):** Interface moderna com fundo preto e contraste otimizado para leitura.
- **Sistema de Dicas (💡):** Cada pergunta possui uma lâmpada com uma dica rápida para ajudar na resposta.
- **Feedback Visual Animado:** 
  - 🟢 **Verde** para respostas corretas, acompanhado do gabarito oficial detalhado.
  - 🔴 **Vermelho** para respostas incorretas, exibindo a resposta certa logo abaixo.
- **Contador de Progresso:** Acompanhamento em tempo real de qual pergunta você está respondendo.

---

## Tecnologias Utilizadas
- **HTML5** (Estrutura da página)
- **CSS3** (Estilização customizada, animações e responsividade)
- **JavaScript (Vanilla)** (Lógica do quiz, verificação de respostas e manipulação do DOM)
